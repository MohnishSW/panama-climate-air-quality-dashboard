# 🌦️ Weather Dashboard (Power BI Project)

A Power BI dashboard project built to analyze and visualize weather data, focusing on temperature trends, humidity, and overall weather conditions across different locations.

---

## 📌 Project Overview

This project transforms raw weather data into an interactive Power BI dashboard. It helps users understand weather patterns, compare conditions across locations, and analyze trends over time using visual analytics.

---

## 📊 Key Features

- 🌡️ Temperature analysis by location
- 💧 Humidity tracking
- 🌬️ Weather condition categorization (Clear, Rain, Clouds, etc.)
- 📈 Trend analysis over time
- 🌍 Location-based filtering
- 📊 Interactive dashboards with slicers and filters
- 📌 KPI cards for quick insights

---

## 🛠️ Tools Used

- Power BI
- Power Query (Data Cleaning)
- DAX (Data Analysis Expressions)
- Weather dataset (API / sample dataset used in project)
